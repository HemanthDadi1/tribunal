SECURITY BY DESIGN

Built to be attacked by the other side’s AI

Evidence is untrusted

Text that tries to instruct the judges is detected, flagged and counted against the person who sent it.

Limits never leave the server

The API never returns a mandate. A test checks every response for leaked limits.

Every message is parsed strictly

Offers are re-parsed as if from a hostile network: exact keys, typed values, bounded sizes.

No single point of judgement

Judges from different providers, so one compromised model can’t swing a ruling alone.

Tribunal · 10

In agent commerce, the counterparty is often another AI working against you. So we assume every message and every piece of evidence is adversarial. Prompt injection is the obvious attack on an AI judge; we detect it, flag it, and penalise the person who tried it, which makes trying it a losing move.
